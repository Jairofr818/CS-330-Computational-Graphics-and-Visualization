# CS-330-Computational-Graphics-and-Visualization
First of all, when working on any software, I define its main goal and break the task into smaller pieces. In this project, I enhanced my skill of planning 3D scene as I defined which objects I would create and which simple shapes will be able to compose them. In my computer desk scene, I created such 3D objects as monitor, webcam, keyboard, mouse, speakers, desk lamp, and pencil holder using shapes such as box, cylinder, sphere, and plane. I used iterative design by creating objects, experimenting with their appearance, modifying their scale, rotation, positioning, textures, and lighting. Such approach may be useful in other projects since it involves breaking of one big problem into several smaller parts.

While developing the program, I realized that it is better to gradually build up and test a program rather than doing everything at once. All through milestones, I added such elements as 3D objects, camera navigation, textures, materials, and lighting. Iteration was very important as I tested the program running it, checked the scene and made some changes in it until the objects were designed and worked properly. I also used reusable functions to make transformations, textures, materials, and rendering of the objects. Now my programming skills are improved as I pay more attention to frequent testing, modularity of code, and building complicated programs step-by-step.

Computer science will enable me to achieve my future goals by providing me with necessary technical and problem-solving skills that I can use everywhere. Concepts of computational graphics and visualization taught me C++, OpenGL, transformations, textures, lighting, shaders, materials, and camera controls. These concepts gave me more insight about integration of math, programming, and visual design in creation of interactive application. Also, these skills may be used in other courses and professional areas such as software development, simulation, game development, virtual environment, and data visualization.
